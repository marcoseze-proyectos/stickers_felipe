# 🌟 STICKERS | Tienda Online Minimalista

Tienda web 100% frontend desarrollada con HTML5, CSS3 y JavaScript nativo, diseñada para exhibir un catálogo de stickers troquelados e impulsar ventas y consultas directas a través de WhatsApp.

## 📁 Estructura del Proyecto

```text
stickers_felipe/
├── docs/               # Carpeta principal pública (sirve para GitHub Pages)
│   ├── css/
│   │   └── style.css   # Estilos unificados de la tienda
│   ├── js/
│   │   ├── api.js      # Catálogo estático de productos
│   │   └── app.js      # Lógica del carrito, filtros y WhatsApp
│   └── index.html      # Página principal
├── uploads/            # Carpeta con las imágenes reales de los stickers
├── .gitignore          # Archivos excluidos del control de versiones
└── README.md
